For secrets that aren’t passwords

Stop autofill from corrupting secret fields.

API keys. Access tokens. Signing secrets. Keep the value your user entered, even when the browser tries to fill something else.

import { mask } from 'secret-input';

const input = mask(element);
input.secretValue = 'sk_test_123';

input.value;       // '•••••••••••'
input.secretValue; // 'sk_test_123'
