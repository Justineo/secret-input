Four ways to handle a secret

Try the same fields in each implementation. Watch for automatic fill and password suggestions.

Autocomplete off

A native password input with autocomplete="off". Browsers may ignore the hint and still classify the pair as login credentials.

New-password

A native password input with autocomplete="new-password". This common workaround prevents silent saved-password fill, but still triggers password and generated-password UI.

CSS masking

A text input with -webkit-text-security: disc when supported. It avoids password UI in some browsers, but masks only visually and Safari still shows autofill UI.

Secret Input

A text input passed to mask(input). Its DOM value holds bullets while browser-written text stays out of state. Native password accessibility cannot be reproduced; undo/redo and IME handling are best effort.
